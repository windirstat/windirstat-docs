WinDirStat is a free, open-source disk usage analyzer for Microsoft Windows. It scans drives and folders and shows how disk space is distributed.

The main WinDirStat project page, source code, and issue tracker are on GitHub.

Features

  • Scanning Scan drives or individual folders, with multithreaded and direct NTFS scanning where available.
  • Disk Usage Views Use sortable lists, extension statistics, Largest Files, and an interactive treemap.
  • Search and Duplicates Filter results, compare logical and physical sizes, and detect duplicate files by content.
  • File Details Inspect permissions and storage tiers, estimate costs, and identify possible storage optimizations.
  • File Operations Open, move, or delete items and run Windows maintenance tools from WinDirStat.
  • Other Tools Watch file-system changes, save or export scans, and configure layouts, portable settings, dark mode, and Explorer integration.

The screenshot follows your system theme. In the treemap, each rectangle represents a file. Area shows size, color shows file type, and nesting shows the folder structure.
