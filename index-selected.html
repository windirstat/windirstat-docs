WinDirStat is a free, open-source disk usage analyzer and cleanup assistant for Microsoft Windows. See what fills your drives and folders, then investigate the files that matter.

Downloads Getting Started

Features

  • Scanning Scan multiple folders, drives, network shares, or MTP devices. Elevate for accelerated local NTFS scans.
  • Disk Usage Views Explore largest files, file types, treemaps, sunbursts, and flame graphs. Compare logical and physical sizes.
  • Search and Duplicates Search by name, size, type, or owner. Compare content hashes, with optional sparse hashing for probable duplicate matches.
  • Permissions and Analytics Inspect permission entries and estimate storage tier costs using file sizes and modification ages.
  • Reports and Monitoring Save and reopen scan snapshots, export CSV/JSON reports, automate scans, and watch file-system changes.
  • Cleanup and Recovery Run cleanup tools or attempt to recover deleted files from local NTFS, exFAT, and FAT drives.

Find Space to Reclaim

  1. Choose drives or folders in Select Drives. Enable duplicate scanning only when needed.
  2. Sort by size, inspect Largest Files, or press Ctrl+F to search. Select an item to locate it in the visualization.
  3. Review items in Explorer before cleanup, then refresh the affected results.

Adjust layouts, fonts, dark mode, and portable settings in Settings. Source code and issue reports are on GitHub.

The screenshot follows your system theme. In the treemap, each rectangle represents a file. Area shows size, color shows file type, and nesting shows the folder structure.
